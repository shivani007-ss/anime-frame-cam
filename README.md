# anime-frame-cam

Turn your webcam into anime by making a frame gesture with your hands.

## Demo
[]

## Features
- Live webcam in your browser
- Hand tracking (no install needed)
- Hold a rectangle shape with your hands to switch to anime mode
- Runs fully in your browser, no video is uploaded

## How to use
1. Open the site and allow camera access.
2. Make a rectangle with both hands (thumbs and index fingers touching).
3. Hold it for half a second.
4. Your camera turns into anime. Do it again to switch back.

## Tech
- HTML, CSS, JavaScript
- MediaPipe Hands
- AnimeGANv2

## Run locally
1. Clone this repo: `git clone [your repo link]`
2. Open the folder in VS Code.
3. Run it with the Live Server extension.
